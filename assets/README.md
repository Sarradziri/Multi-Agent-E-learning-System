# Assets

Drop demo media here and reference it from the root `README.md`.

Suggested files:

| File | What to capture |
|------|-----------------|
| `dashboard.png` | The Streamlit dashboard landing page |
| `xai_explorer.png` | SHAP / LIME / counterfactual explanation view |
| `learning_path.png` | The A* / Q-Learning generated learning path |
| `demo.gif` | A 10–20s screen recording of a full run (pick a student → recommendations → explanation → path) |

To record a GIF on Windows: use the Xbox Game Bar (`Win+G`) or [ScreenToGif](https://www.screentogif.com/).

Once added, embed them in the root README, e.g.:

```markdown
![Dashboard](assets/dashboard.png)
```
